服务器配置

服务器 IP 可以与 TLS 名称不同；证书仍必须匹配 TLS 名称。配置保存后会清除当前账号会话。只接入服务端显式开启的通用模式，不会回退到私有平台或本地账号。

账号认证成功与游戏进服是两个阶段。游戏启动需要严格隔离宿主及管理员权限；客户端版本不匹配会拒绝启动。请勿同时使用原启动器的本地“开始游戏”，避免桥接端口冲突。

使用说明

先向服主取得通用模式 IP、端口、证书名称、身份域和频道描述文件，再保存并校验。注册或登录后，使用本页的 MeowLink 启动入口。

关闭浏览器标签页不会停止连接程序。停止实例只处理本程序创建的宿主与桥接；程序不会安装 DLL、修改原启动器或访问玩家数据库。
