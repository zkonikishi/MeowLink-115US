# MeowLink-115US

MeowLink 是面向 **115US（115 版本服务端）** 的多人联机 / 组队 mod，负责 Meowopia mod 体系中的「多人域」能力：组队、同城镇可见、普通世界共享与副本共享。

本仓库是 MeowLink 的 **115US 域层源码快照**，只包含本项目自有代码：不包含 115US 上游服务端源码、不包含游戏本体 / 游戏资源（PVF 等）、不包含客户端二进制，也不包含预编译宿主程序。

> 当前状态：域层源码可独立编译测试；实机联机（原生协议接线、实机组队 / 进图、生产准入）尚未接通，115 上游的多人世界本体也尚未实现，本仓库不构成可用性承诺。

## 双模式

MeowLink 设计上分两种部署模式，二者共用本仓库的多人域层，差异只在账号 / 认证接入层：

| 模式 | 账号与认证 | 源码范围 | 接入说明 |
| --- | --- | --- | --- |
| **自定义模式** | 平台认证链路：平台 UID 换取服务端凭据（现有 MeowLink / Meowopia / platformDB 链） | 定制层不公开，不随本仓库分发 | 具体使用方式不公开 |
| **通用模式** | 目标服务器自己的用户名 / 密码账号与存档（数据库由目标服务器管理），不依赖 Meowopia 平台身份，无邮箱 / 平台 UID | 本仓库即通用模式的公开源码 | 部署方自备服务端、账号与配置 |

两种模式均支持本地或云端部署；切换模式必须清会话、隔离存储、失败不回退，且不得伪造平台身份。

## 内容

| 目录 | 内容 |
| --- | --- |
| `domain/` | Go 域层（module `meowlink`，Go 1.26）：组队、普通世界、副本共享与协议体的离线解码 |
| `client/native-party-gate/` | 客户端原生组队门控的 C++ 补丁：只替换「成员本地性」判断，保留原生成功路径 |
| `client/legion-party-hud/` | 军团真实队员 HUD 客户端 Mod（C，本地 ModStart 宿主加载） |
| `docs/` | 架构与接入说明、域文件清单（SHA256） |

### domain/

- `internal/party` — 组队域：Hub、注册表、租约（lease）、招募目录、组队设置、通知、观察者、团本营地/重入/保留/投影、月色进度、受控角色、公开资料。
- `internal/ordinary` — 普通世界共享域（2..4 人）：以 `dungeon.WithRoomCommit` 约束事务与锁顺序。
- `internal/dungeon` — 副本共享域：共享戳（stamp）与房间提交守卫。
- `internal/partywire` — B823 协议逻辑体的**离线解码**：只解码已单独证明的逻辑体，不做传输填充推断、不做成功投影、不做授权判定。

## 状态与边界

- 域层是可独立测试的源码快照；**实机联机验收（原生协议接线、实机组队/进图、生产准入）尚未完成**，本仓库不作任何可用性承诺。
- 域层不拥有游戏状态：角色、会话、好友、资产交易的权威仍在服务端/平台；本仓库不包含账号体系、支付或部署配置。
- 客户端补丁只修改运行时进程内存中的显示/门控逻辑，不修改磁盘上的游戏文件。
- 接入方式见 [`docs/integration.md`](docs/integration.md)；架构与边界见 [`docs/architecture.md`](docs/architecture.md)。
