# 军团真实队员 HUD（NB77 候选）

只隐藏伊斯大陆、次元回廊、幽暗岛、维纳斯、末世录的纯空位；不改变名册、容量、入场限制、血量或奖励。真实角色（包括死亡队员）照常绘制。原生断线队员队列还有记录时，保留原等待/重连显示。团本专用小队框没有套用此补丁。

原生绘制函数 `14553f4d0` 的调用点 `14553f6b9` 获取槽位角色后，只用返回值判空（非空跳至 `14553fafc`），不会解引用或发布该值。本补丁仅替换这个调用点：原角色为空、当前模式在明确军团范围、断线队列游标等于末尾时，关闭该空框并返回仅用于跳过绘制的非空标志。绝不往队伍中加入假角色，也不压缩原来的槽位编号。

转接代码将原循环 RBX（队列游标）、[R13]（框对象）放入 Windows x64 的第三、第四参数，尾跳至普通 C 函数。保留原生栈、返回地址和非易失寄存器。启动时校验五处指令，暂停同进程线程后再次核对并只修改五字节调用；窗口管理器已存在则拒绝迟加载。不修改磁盘上的 DFO.exe，不附加或启动游戏，不绕过客户端保护。

使用本地宿主 ModStart 加载。状态写入 `.115us-mods/legion-party-hud-<PID>.status.json`。编译与静态检查通过不等于实机验收；需验证两人进图、队员死亡、断线重连和返回等待室。
